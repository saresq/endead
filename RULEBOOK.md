# Zombicide 2nd Edition — Rules

The printed CMON *Rules & Missions* rulebook (68 pages), transcribed into one chapter per file
under [`rules/`](rules/), plus the data the book does not carry.

**`rulebook.pdf` in this directory is the final authority.** Every section below cites the page it
came from, so a disputed detail is one `pages:` read away. Where a fact is *not* in the rulebook —
Skill trees, card stats, per-card Zombie amounts — the block is marked **Not in the rulebook** and
names its source.

This file is an index. It holds no rules. Do not add any.

## Conventions

- **Page markers.** Every section carries the PDF page it was transcribed from, as `*p.27*` or `[p.27]`.
  Cross-references inside quoted text keep the book's own `(P. 27)` wording; resolve them with the
  [page map](rules/99-quick-reference.md#page-map).
- **Flavor text** is a blockquote with an em-dash attribution. It is part of the transcript, not commentary.
- **Die faces.** The book prints die results as pip icons. They are transcribed as the numeral they show
  (`She rolls 2 and 5`), read off the page at high magnification — a text extraction renders them all as
  the same bullet and silently loses the value.
- **Diagram captions** are kept under a `*Diagram captions, p.N:*` list. The diagrams themselves are only
  in the PDF — which is why Mission maps cannot be built from these files alone.
- **Derived content** is fenced by a `> **Not in the rulebook**` block naming its source. Everything outside
  such a block is the printed text.
- **Endead decisions** appear as `> **Endead implementation note**` and state the rule they implement.
  There is one, in [10-zombie-phase.md](rules/10-zombie-phase.md#step-2-spawn).
- **Anchors, not line numbers.** Code comments reference `rules/<file>.md#<heading>`. Headings are stable;
  line numbers are not. Do not reintroduce `RULEBOOK.md:NNN` references.

## Searching

```bash
grep -rn -i "targeting priority" rules/     # find the rule
grep -rln "Molotov" rules/                  # which chapters touch it
sed -n '/^## Friendly Fire/,/^## /p' rules/11-combat.md
```

Each chapter is small enough to read whole; prefer opening the one file over grepping all of them.
